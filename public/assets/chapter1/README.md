# Chapter 1 / WELCOME — アセット配置ガイド

ここに OPENING（0:00〜0:14）で使う画像素材を置く。
コードからは絶対パス `/assets/chapter1/<ファイル名>` で参照する
（Vite の `base` が自動で前置されるため、`/project-piero/...` は書かない）。

実装側は「**存在するファイルだけを使い、無いものは自動でフォールバック**」する。
まずは最小構成から始め、後からレイヤーを追加すれば演出の忠実度が上がる。

---

## 共通仕様

- 形式: **PNG**（PIERO・ネオン・風船・車両など重ねる素材は**背景透過**）／背景ベースは JPG 可
- 解像度: 長辺 **2560px 目安**（高DPI対応）。1枚あたり **1.5MB 以下**、合計 **10MB 以下**を推奨
- **位置合わせ（最重要）**: PIERO を分割する場合、各パーツPNGは
  **同一キャンバスサイズ・同一位置**で書き出す（重ねるだけでピタリと合う状態にする）
- 色空間: sRGB

---

## Tier 0 — 最小構成（これがあれば実装開始できる）

| ファイル名 | 内容 |
|---|---|
| `park.png` (または `park.jpg`) | 夜の遊園地の背景（**PIEROは含めない**） |
| `piero.png` | PIERO 本体（**背景透過**、顔まわり一体でも可） |

> この2枚だけでも「暗転 → 遊園地が目覚める（明度ランプ）→ スポットライトでPIERO出現 →
> タイトル電飾 → CHOOSE表示 → 呼吸/パララックス」までは実装できる。
> ただし「ネオンが順番に点灯」「鼻→顔→髪→瞳の順の出現」「瞳だけ動く/瞬き」は Tier 1/2 が必要。

## Tier 2 — PIERO パーツ分割（部位ごとの出現・視線・瞬き用）

すべて**同一キャンバス・同一位置**の透過PNGで書き出すこと。

| ファイル名 | 内容 | 演出 |
|---|---|---|
| `piero-hat.png` | 帽子 | ヒントで「フワッ」と浮く |
| `piero-hair.png` | 赤い髪 | 出現3番目 |
| `piero-face.png` | 白い顔ベース（鼻・目・口を除く） | 出現2番目 |
| `piero-nose.png` | 赤い鼻 | **出現1番目**（最初に見える） |
| `piero-eyewhite-l.png` / `piero-eyewhite-r.png` | 左右の白目 | 固定 |
| `piero-pupil-l.png` / `piero-pupil-r.png` | 左右の**青い瞳**（動かす対象） | 視線移動・マウス微反応 |
| `piero-mouth.png` | 口 | Part 2 で使用 |
| `piero-body.png` (任意) | 体・襟 | 呼吸で僅かに動く |

> Tier 2 を入れると「暗闇から鼻→顔→髪→瞳の順に浮かび上がり、瞳だけがこちらを見て一度瞬きする」
> というストーリーボードのコア演出が再現できる。
> 素材が無い部位は自動でスキップ（例: 瞳PNGが無ければ視線移動は行わない）。

## 実装の進め方

1. まず **Tier 0（`park` + `piero`）** を置く → この時点で OPENING を実装・デプロイして確認
2. 余裕があれば **Tier 1 → Tier 2** を追加 → 追加のたびに演出を差し込み、忠実度を上げる

配置が終わったら「配置しました」と知らせてください。存在する素材を検出して OPENING を実装します。
